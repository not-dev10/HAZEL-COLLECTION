## ❓ FAQ

**Q: Where do I access the admin panel?**
A: Navigate to `http://localhost:5173/admin`

**Q: How do I import products via CSV?**
A: Go to Products page → Click "Import CSV" → Upload file with format: name,sku,price,stock,category

**Q: How do I connect to my backend?**
A: Replace the mock data calls in each page with your API endpoints. See [ADMIN_PANEL_GUIDE.md](./frontend/ADMIN_PANEL_GUIDE.md#api-integration).

**Q: Is the admin panel mobile-friendly?**
A: Yes! It's fully responsive with a hamburger menu on mobile devices.

**Q: Can I customize the colors?**
A: Yes! Update the Tailwind config and component classes. Default theme uses purple (#9333ea) and pink (#ec4899).
