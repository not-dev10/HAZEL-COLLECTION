# Frontend Project

This is the React + Vite + TypeScript frontend for the Didi Fashion e-commerce platform.

See the [main README](../README.md) for project structure and general information.

## Running Frontend

From the project root:
```bash
npm run frontend:dev      # Development with HMR
npm run frontend:build    # Production build
npm run frontend:preview  # Preview production build
```

Or from the frontend directory:
```bash
npm run dev
npm run build
npm run preview
```

## Frontend Features

- Interactive animated Add to Cart button
- Product catalog with filtering
- Mini cart with item management
- Responsive design with Tailwind CSS
- Modern UI components from shadcn/ui
